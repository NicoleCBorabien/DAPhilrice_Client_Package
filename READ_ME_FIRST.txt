PHILRICE SPECIFIC TAG FORECASTING
=================================

CLIENT INSTRUCTIONS

1. Open:
   02_Source_Data\Forecast_Input_Template.xlsx

2. Enter the employee's monthly workload data in the Data sheet.

3. Save the workbook and CLOSE Excel.

4. Double-click:
   RUN_FORECAST.bat

5. When forecasting is complete, the result workbook opens automatically.
   A copy is also saved in:
   01_Results\PhilRice_Specific_Tag_Forecast_Results.xlsx

THAT IS ALL YOU NEED TO DO.

IMPORTANT
- Do not rename or delete the folders in this package.
- Do not edit files inside 03_Model_and_Code.
- Internet access is required during the first run so the forecasting
  components can be installed.
- Python 3.12 is recommended.
- On company-managed computers, Windows security policies may prevent
  Python scientific libraries from running. If setup is blocked, contact IT
  or the project administrator.
